# KØROS' ARES Materials

## Overview

This is material that I have created for [DC ARES NE](https://dcaresne.wixsite.com/dcaresne).

## Building

### Prerequisites

- PowerShell
- Node + npm
- [backslide](https://github.com/sinedied/backslide)
    - Consider [Backslide Docker](https://gitlab.com/mpolitze/backslide-docker) with Docker/Podman for slide development

### Building

Run `build.ps1` to build things. It may or may not work. I spent enough time getting this to build on a Windows machine and 
didn't so much as test it once on other platforms. YMMV.
